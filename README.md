# 路線図ひと筆

架空の地下鉄の路線図で、**始発から終点まで全部の駅を1回ずつ**通る道を探すパズルです。道はどの路線図も1つだけ。

- 遊ぶ：https://satou-aaaaa.github.io/rosen-hitofude/
- 「今日の3路線」（各駅・快速・急行）はだれでも同じ問題で1日1回。結果は星の文でシェアできます。
- 上級「特急」は52駅・ヒントなし。練習は何度でも。何路線続けて開通できるかの「とことん」（ヒントは何回でも・「ここで降りる」まで続く・自己ベストを残す）もあります。毎日の乗車スタンプと、開通した路線の数で称号が上がります。
- 駅を押すか、指でなぞって進みます。時間制限はありません。
- 記録はあなたのブラウザの中だけに残ります。ホーム画面に置くと、電波が無くても遊べます。

応援：https://ko-fi.com/satouaaaaa （遊ぶのはずっと無料）
